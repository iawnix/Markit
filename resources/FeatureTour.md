# 使用 Markit

## 创建与编辑

从左上角菜单新建文稿或打开 Markdown 文件。打开的文稿显示在标签栏中，底部模式按钮用于切换即时排版和源码编辑。

即时排版支持 **粗体**、*斜体*、~~删除线~~、`行内代码`、链接、列表和公式。点击排版内容即可编辑对应的 Markdown 源码。

## 浏览文稿

- **文件**：浏览当前工作区，点击文件打开。
- **大纲**：查看标题结构，点击标题跳转。
- **搜索**：查找文本并执行替换。

拖动侧栏边缘可调整宽度。使用 `Ctrl+J`（macOS 为 `Cmd+J`）切换专注模式。

## 表格与公式

在表格单元格中打开右键菜单，可添加、删除行列。公式使用 `$...$` 或 `$$...$$` 分隔：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 保存与导出

按 `Ctrl+S`（macOS 为 `Cmd+S`）保存。首次保存时选择文件位置。关闭有未保存修改的文稿或窗口时，可以保存、丢弃修改或取消关闭。

菜单提供 HTML、打印 / PDF 和 PNG 长图导出。

## 外观与插件

在设置中选择浅色、深色或系统主题，调整字体、字号和阅读宽度。

通过“安装插件”导入 `.markit-plugin` 包。Zotero 检索和参考文献用法见[参考文献与公式](AcademicWriting.md)。

## 独立文稿与项目目录

“打开文件”（`Ctrl+O` / `Cmd+O`）只打开文稿，不会自动创建项目。文件面板的“已打开文稿”可以切换多个文稿。

“打开文件夹”（`Ctrl+Shift+O` / `Cmd+Shift+O`）直接浏览原目录，不复制文件，也不生成专有项目格式。项目树支持展开子目录、定位当前文稿、预览图片和通过系统应用打开其他文件。打开项目外的文稿不会改变项目根目录。关闭或切换项目会保留已打开的文稿。

新文稿首次保存时，项目模式默认使用当前选中的目录。项目目录和手动展开的目录会在下次启动时恢复。目录变化后可手动刷新，窗口重新获得焦点时也会刷新。

## 图片与附件

通过“插入图片”、粘贴截图或拖入图片，Markit 会将图片复制到文稿旁的资源目录。例如 `旅行笔记.md` 对应 `旅行笔记.assets/`，Markdown 中保存相对引用。没有插图就不会创建资源目录。尚未保存的文稿首次插图时会先选择保存位置；取消保存会取消这次插图。

图片路径始终相对于 Markdown 文件，与是否打开项目无关。已有的 `assets/`、`images/` 等路径不会在普通保存时被修改。项目内可以使用 `../assets/图.png` 共享图片；独立文稿访问所在目录之外的图片时，可在图片提示条中选择其所在文件夹，授权仅用于这篇文稿的图片访问。

在项目树中点击图片可预览，再点击“插入当前文稿”直接引用它。图片在其他磁盘、无法使用相对路径时，复制进文稿的资源目录。批量图片导入会先校验整批内容，写入失败则撤销本次新增文件。

普通保存只更新 Markdown，不会清理图片。撤销插图或删除图片引用也不会自动删除附件。手动移动、分享文稿时，需要同时携带配套资源目录。

## 另存为与打包分享

- **另存为**（`Ctrl+Shift+S` / `Cmd+Shift+S`）：复制实际引用的本地图片，调整新文稿中的图片路径，保留原文稿和原资源。缺失或未授权的图片会阻止生成不完整副本。非图片链接保持原样。
- **打包导出 ZIP**：包含当前 Markdown 内容与引用的本地图片，解压后即可打开。
- **导出 HTML**：将本地图片嵌入 HTML，移动 HTML 文件也能显示图片。

网络图片保持原 URL，离线分享时需要先将其下载并作为本地图片插入。打印 / PDF 和 PNG 长图仍可从菜单导出。
