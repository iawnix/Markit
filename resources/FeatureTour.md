# 使用 Markit

## 创建与编辑

从左上角菜单新建文稿或打开 Markdown 文件。打开的文稿显示在标签栏中，底部模式按钮用于切换即时排版和源码编辑。

即时排版支持 **粗体**、*斜体*、~~删除线~~、`行内代码`、链接、列表和公式。点击排版内容即可编辑对应的 Markdown 源码。

## 浏览文稿

- **文件**：浏览当前工作区，点击文件打开。
- **大纲**：查看标题结构，点击标题跳转。
- **搜索**：查找文本并执行替换。

拖动侧栏边缘可调整宽度。使用 `Ctrl+J`（macOS 为 `Cmd+J`）切换专注模式。

## 表格与公式

在表格单元格中打开右键菜单，可添加、删除行列。公式使用 `$...$` 或 `$$...$$` 分隔：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 保存与导出

按 `Ctrl+S`（macOS 为 `Cmd+S`）保存。首次保存时选择文件位置。关闭有未保存修改的文稿或窗口时，可以保存、丢弃修改或取消关闭。

菜单提供 HTML、打印 / PDF 和 PNG 长图导出。

## 外观与插件

在设置中选择浅色、深色或系统主题，调整字体、字号和阅读宽度。

通过“安装插件”导入 `.markit-plugin` 包。Zotero 检索和参考文献用法见[参考文献与公式](AcademicWriting.md)。
